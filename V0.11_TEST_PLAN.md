# Bifrost v0.11 stabilization test plan

This checklist is for testing the Android APK and Windows installer produced by GitHub Actions. Test with one Android phone and one Windows PC on the same local network.

## Before testing

Install the new Android APK over the existing Bifrost installation. Do not uninstall first. Install the Windows installer, then confirm the old app data and device name remain available.

Record the phone model, Android version, Windows version, and the Bifrost version shown in Settings → About.

## Core transfer tests

| Test | Expected result |
|---|---|
| Windows sends a small file to Android | Android asks for approval and the file appears in Download/Bifrost |
| Android sends a small file to Windows | Windows receives the file and History records it |
| Send a large file | Nearby, History, and Android notification show progress, speed, and ETA |
| Cancel from sender | Both sides stop and History says Cancelled |
| Cancel from receiver | Sender stops and partial files are cleaned up |
| Send several files | Each file shows its own queue state and the final summary is correct |
| Interrupt the connection | A failed sent file can be retried from History |

## Native integration tests

### Android Share

Select one file in Gallery or Files, tap Share, choose Bifrost, confirm it appears in the Nearby queue, and send it. Repeat with multiple files.

### Windows Explorer

Right-click a file and choose Send with Bifrost. Confirm Bifrost opens with that exact file queued. Repeat with a filename containing spaces.

### APK History action

Receive an APK, open its History entry, choose Install APK, and confirm Android opens the installer. If Android requests permission to install unknown apps, allow it only if you trust the APK.

## Visual tests

Open Bifrost several times and confirm the splash appears briefly each time. Check Day, Sunset, and Night from Settings. Confirm the selected theme survives closing, reopening, and installing an update. Check that the Mistical Spring font affects only the bold Bifrost splash title.

Confirm the new launcher icon is sharp on the Android launcher and in the Windows shortcut.

## Settings and persistence

Change the device name, save location, theme, background activity setting, and trusted-device list. Restart both apps and confirm each choice remains.

Open Settings → Help & Troubleshooting and confirm the instructions are understandable. Open Settings → About and confirm the credit line and version are correct.

## Results to report

For each failure, record the exact step, the file type and size, the device pair, whether the app was foregrounded or backgrounded, and any visible error message. Screenshots are especially useful for notification or layout problems.
