# Bifrost protocol

The complete versioned protocol will be designed and documented before networking code is written in Milestone 2.

The planned protocol will cover:

1. Device information exchange.
2. Transfer offers and accept/decline responses.
3. Chunked streaming for large files.
4. Per-file SHA-256 checksums.
5. Cancellation and clean retry behavior.
6. Friendly, documented error codes.
7. HTTPS certificates and pairing fingerprints.

No network protocol is implemented in Milestone 1.
